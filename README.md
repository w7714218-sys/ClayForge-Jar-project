# ClayForge-Jar-project
Clayforge is a local website which aim is to create a jar in a .stl format in order you can print it in your 3d printer 

Comando 							¿Qué hace?										¿Por qué lo uso?
node -v 							Muestra la versión de Node.js instalada.		Comprobar que Node.js estaba correctamente instalado.
npm -v								Muestra la versión de npm.						Verificar que el gestor de paquetes funciona.
npm init -y							Crea automáticamente un package.json.			Inicializar el proyecto como un proyecto de Node.js.
npm install three					Instala la librería Three.js.					Necesitamos Three.js para crear y renderizar el modelo 3D del jarrón.
npm install -D vite					Instala Vite como dependencia de desarrollo.	Vite nos proporciona un servidor local rápido y soporta módulos ES de forma nativa.
npm run dev							Inicia el servidor de desarrollo de Vite.		Ejecutar la aplicación localmente mientras programamos.


Node.js + npm + Vite + Three.js + GitHub.
